# Conversational Experience Remotion source

This workspace contains editable React compositions for the Antbuildz AI Conversational Experience page.

Run `npm run studio` to preview the compositions. Stop Studio before running `npm run render`, which writes the website MP4 and poster assets into `../public/`. On this Mac, keeping Studio open prevents the production video bundler from completing.

The shared source data intentionally avoids price, availability and booking-confirmation claims. It uses the documented Toyota 8FBMT50 and Hyster J3.5XN forklift capacity records as illustrative comparison content. See `../app/HOME-EQUIPMENT-SOURCES.md` for the supporting sources and operational boundaries.
